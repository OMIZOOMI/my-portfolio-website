## Visual provenance and limits

The evidence figure is an original semantic HTML diagram derived from the linked implementation and controlled test. It is explicitly labelled **“Implementation diagram · Controlled test input.”** Its input is a shortened excerpt of the fixture document; the tag's trailing whitespace is normalized. The observation count and finding follow the parser/rule above. No remote scan, screenshot, scan ID, timestamp, performance measurement or customer data is fabricated. Empty `alt` is distinct from missing `alt`, and the figure explains that HTML alone cannot judge an image's purpose.

The repository README, implementation, dependency manifests, lockfile and relevant test sources were read through GitHub. The external Veyra test suite was **not executed**; reading its tests is not a passing test run. Portfolio rendering, catalogue/reference regressions, production compilation and actual browser checks are recorded in `verification.md`.
