# Screen view, readability, Sound settings and Terminal

Screen view expands the existing projected desktop to the page with a 680 ms perspective-preserving zoom. It is a page-filling view, not a browser Fullscreen API request. The same Drei Html React root, desktop, editors and media components remain mounted. Switching Html's transform mode would destroy its root, so the implementation changes only the projection wrapper's presentation and animates its inner surface from the measured four corners. Reduced motion skips the zoom. Back to laptop is always available alongside the corner Settings control; Escape returns when an editor or app menu does not own it.

Settings → Accessibility offers 100%, 115%, 130%, and 145% interface sizes and three separate folder/file icon sizes. Scaling changes the usable desktop's local dimensions; windows use their existing bounds and coordinate conversion. The Dock scrolls on narrow desktops and menus wrap instead of clipping. New windows and windows refitted after a desktop-size change clear the Dock so controls remain visible; ordinary dragging still reaches behind it, and changing Dock size alone does not pull windows away from the screen edge. Settings also reserves scroll clearance for its last controls. Preferences use a separate, validated, small storage entry; view mode is session-only. Window/drag/editor data is never serialized with these preferences. Desktop icons clamp to the actual desktop size.

The corner launcher now uses a gear and is labelled Settings. Workspace backgrounds remain in that panel. The existing keyboard sound preference and runtime are preserved, with their control and recording credits moved to macOS Settings → Sound. Existing on/off preferences remain valid.

Terminal keeps the application's shared window chrome. Its quiet monospace interface offers command suggestions, command recall, seven linked projects, detailed project views, skills, experience and contact. Responses reveal progressively with a permanently reachable command prompt and one bounded timer at a time (32 ms updates, approximately 286 characters/second); new commands settle older output, and Show now or Escape completes it immediately. Reduced motion shows complete responses. Minimize/page-hidden pauses the active stream; close removes it. History is memory-only and bounded to 60 commands. Input is interpreted as local portfolio commands, never evaluated as shell/HTML. Links open real repository URLs in another tab. Output avoids rapid screen-reader live announcements.
